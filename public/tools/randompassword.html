Password Entropy Explained

Password entropy measures how hard a password is to guess. It depends on password length and the size of the character pool. A 16-character password using only numbers has about 53 bits of entropy, while a 16-character password using uppercase, lowercase, numbers and symbols has about 95 bits. For important accounts, use at least 12 characters with mixed character types. Avoid birthdays, common words and repeated patterns. Use a password manager to store unique passwords for every account.
