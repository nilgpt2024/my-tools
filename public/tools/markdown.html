What Is Markdown?

Markdown was created by John Gruber in 2004 with the goal of being easy to read and easy to write. Instead of clicking formatting buttons, you write plain text with symbols. For example, surround a word with double asterisks **word** to make it bold, or start a line with a hash # to create a heading.

Because Markdown files are plain text, they work on every operating system and can be edited in any text editor. They are also version-control friendly, which is why developers love Markdown for documentation.
